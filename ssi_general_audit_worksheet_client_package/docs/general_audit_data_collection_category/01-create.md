# Create Data Collection Category

> **Module:** `ssi_general_audit_worksheet_client_package`\
> **Model:** `general_audit_data_collection_category`\
> **Menu:** Configuration > Standard & Regulation > Data Collections > Data Collection
> Categories\
> **Actor:** user in group _Data Collection Category_\
> **State:** `—` → `—`

## Pre-Condition

- **Access:** User is in group _Data Collection Category_.

## Flow

1. Open the **Configuration > Standard & Regulation > Data Collections > Data Collection
   Categories** menu. If **Standard & Regulation** is not visible in the top menu bar,
   click the **+** button at its right end first. The menu list that opens shows
   **Standard & Regulation** with its entries below it.
2. Click the **Create** button. _(16.0 and later: "New")_
3. Fill in the required fields:
   - **Name**: name of the category.
   - **Code**: unique identifier. Type `/` if no identifier is needed.
4. Click **Save**.

## Post-Condition

- A new Data Collection Category is created and is **Active**.
- The category can be selected on a Data Collection record.
