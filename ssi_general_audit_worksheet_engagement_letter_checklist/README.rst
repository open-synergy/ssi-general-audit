=====================================================
General Audit Worksheet - Engagement Letter Checklist
=====================================================

This module provides the worksheet for documenting the **engagement letter
review checklist** as required by ISA 210 / SA 210 (Agreeing the Terms of
Audit Engagements).

Before accepting or continuing any audit engagement the auditor is required
to verify that all preconditions for an audit are present and that the
engagement letter has been reviewed and confirms the agreed scope, the
responsibilities of management and of the auditor, and the expected form of
the auditor's report.

The worksheet in this module covers:

1. **WS.010.1 — Engagement Letter Checklist** — A structured Yes / No / N-A
   checklist that systematically verifies each mandatory element of the
   engagement letter before fieldwork commences.

**Key features:**

- Captures responses for all engagement-letter requirements in a single view
- Follows the standard worksheet workflow: Draft → Open → Confirm → Done
- Checklist items are configurable via the item master

**Models:**

- ``general_audit_ws_d8aaebc``          — WS.010.1 Engagement Letter Checklist
- ``general_audit_ws_d8aaebc.checklist`` — Detail line (one per checklist item)
- ``general_audit_ws_d8aaebc.item``      — Checklist item master

**ISA / SA references:** ISA 210 / SA 210 — Agreeing the Terms of Audit
Engagements


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-general-audit
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *General Audit Worksheet - Engagement Letter Checklist*
6.  Install the module
